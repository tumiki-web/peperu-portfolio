# スナック ぺぺル Webサイト

福岡市早良区小田部の「スナック ぺぺル」公式サイトとして制作する、1ページ完結型の静的Webサイトです。

## ファイル構成

- `index.html` — ページ本体
- `assets/css/style.css` — レイアウト・デザイン・レスポンシブ対応
- `assets/js/main.js` — スマートフォンメニュー・控えめな表示演出
- `assets/images/original/` — 支給された元画像（保持・上書き禁止）
- `assets/images/web/` — Web表示用に最適化した画像
- `assets/icons/favicon.svg` — ファビコン

## ローカル確認

静的ファイルを配信できるローカルサーバーで、このフォルダを公開して確認してください。

## 公開前の確認事項

- `interior-main.webp`、`atmosphere-whisky.webp`、`atmosphere-karaoke.webp`はレイアウト確認用の仮画像です。公開前に実店舗で撮影した画像へ差し替える予定です。
- 元画像の縦横比に近い画像へ差し替えると、現在の構図を維持しやすくなります。
- Google Mapsの導線は住所検索リンクです。正式な店舗URLが確定した場合は、`index.html`のリンク先を差し替えてください。
